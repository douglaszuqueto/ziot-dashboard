# Design System Guardrails

The dashboard design is approved by the client. Preserve it.

## Do

- Reuse existing components from `src/components/ui`.
- Reuse existing module card/table/chart patterns.
- Preserve page grid, icon placement, paddings, radius, and color hierarchy.
- Keep dashboards full-width/admin-style, not boxed blog layout.
- Add visual states using existing empty/error/loading components.

## Do Not

- Add decorative cards unrelated to domain.
- Change hero/header/sidebar/navbar structure without request.
- Replace approved icons.
- Change spacing scale casually.
- Add new color language outside brand system.
- Make AI-looking generic dashboards.

## Before Editing Visuals

- Inspect current page.
- Identify minimal component to change.
- Keep existing markup shape where possible.
- After change, compare page to original intent.
