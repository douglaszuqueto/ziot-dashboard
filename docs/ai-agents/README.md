# AI Agent Playbooks

This folder guides agents changing the customer dashboard.

## Use These First

- `dashboard-feature.md`: add a page, widget, or module behavior.
- `api-integration.md`: connect new backend endpoints.
- `design-system-guardrails.md`: preserve approved visual design.
- `review-checklist.md`: check before commit.

## Core Rule

Functional changes can be added. Approved visual design cannot drift without explicit user request.
